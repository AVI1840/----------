# בחירת גמלה — סעיף 320

כלי להשוואה בין גמלת שאירים לנכות כללית במצב של כפל זכאות.
מיועד לפקידי ביטוח לאומי לצורך חישוב והמלצה על הגמלה המיטבית.

## טכנולוגיה
- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4

## הרצה מקומית
```bash
npm install
npm run dev
```

## בנייה
```bash
npm run build
```

## מבנה תיקיות

```
│   └── FeedbackModal.tsx
├── App.tsx
├── index.css

```
